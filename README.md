# 카카오톡 여행 추천 챗봇 (MVP)

카카오톡 채널에 **"경주 여행"** 또는 **"부산에서 둘이 강릉 다음주 토요일"** 처럼 한 문장을 보내면
기차 시간표, 숙소, 가볼 곳, 먹거리를 카드로 추천하는 **스킬 서버**입니다.
예약과 결제는 하지 않고, 코레일·SRT·숙소 예약 페이지로 연결합니다.

- **출발지 (전국 150개 시·군)**: 문장에 쓰면 그대로 씁니다. "해남에서", "김천 출발", "부산발", "철원 → 강릉", "홍천 담양 여행"처럼 써도 됩니다.
  안 쓰면 그 사용자가 **지난번에 쓴 출발지**를 쓰고, 처음이면 서울을 씁니다.
  - [출발지 바꾸기] 버튼은 **두 단계**입니다. 먼저 [서울][부산][대구][대전][광주][경기·인천][강원][충청][전라][경상] 중에서 고릅니다.
    도 단위를 고르면 그 지역 시·군이 8곳씩 나오고, [다음 ▶]으로 넘깁니다. 사람이 많은 도시부터 나옵니다.
  - 기차역이 없는 곳은 가까운 역을 찾아 "🚉 기차는 목포역에서 타요"처럼 알려 줍니다. 25km 안쪽으로 조금 더 가면 KTX역이 있는 경우에는 KTX역을 고릅니다.
  - 예산, 장수, 영광, 고령, 진도처럼 **일상 단어와 겹치는 지명**은 "예산에서 출발"처럼 "에서"나 "출발"을 붙여야 지명으로 알아듣습니다.
    ("예산 10만원으로 경주 여행"을 예산 출발로 잘못 읽지 않게 하려는 것입니다.) 버튼으로 고르면 문제없습니다.
  - "부산 해운대 여행"처럼 30km 안쪽의 가까운 두 곳을 쓰면, 출발지가 아니라 한 여행지를 자세히 말한 것으로 봅니다.
- **추천**: 인기 여행지 18곳은 **직접 고른 숙소·가볼 곳·먹거리**를 보여 줍니다. 왜 좋은지, 가격대, 걷기 난이도를 함께 적었습니다.
  그 밖의 지역은 카카오 장소 검색으로 실제 숙소·명소·식당을 보여 줍니다.
- API 키가 **없어도** 바로 동작합니다. 이때 기차 시간표는 예시이고, 인기 여행지 밖의 지역은 카카오맵 검색 링크만 나옵니다.
- 기획 배경, API 조사, 화면 설계는 [docs/기획-조사.md](docs/기획-조사.md)에 있습니다.

> 🚀 **실제 카카오톡으로 테스트하려면** [docs/1단계-출시-가이드.md](docs/1단계-출시-가이드.md)를 순서대로 따라 하세요.
> 테스터에게 보낼 문구와 인터뷰 질문은 [docs/테스터-안내문.md](docs/테스터-안내문.md)에 있습니다.

## 1. 내 컴퓨터에서 실행하기

**가장 쉬운 방법 (Windows)**: 폴더 안의 **`실행.bat`** 을 더블클릭하세요.
설치가 필요 없는 Node.js가 `.node` 폴더에 들어 있어서, 검은 창이 뜨고 잠시 뒤 브라우저에 미리보기가 열립니다.
검은 창을 닫으면 서버가 꺼집니다. 자동 테스트는 `테스트.bat` 을 더블클릭하면 됩니다.

터미널에서 직접 실행하려면 [Node.js](https://nodejs.org) 18 이상(LTS)을 설치해야 합니다. 다른 패키지는 필요 없습니다.

```bash
cd senior-ai
npm start
```

브라우저에서 <http://localhost:3000> 을 열면 **카카오톡 흉내 미리보기**가 나옵니다.
문장을 입력하거나 바로가기 버튼을 눌러 보세요. 각 응답 아래 "JSON 보기"를 누르면
카카오로 보내는 실제 데이터를 볼 수 있습니다.

그 밖의 확인 방법:

```bash
npm test
```

```bash
node scripts/try.js "부산에서 둘이 경주 다음주 토요일"
```

```bash
curl -X POST http://localhost:3000/skill -H "Content-Type: application/json" -d "{\"userRequest\":{\"utterance\":\"경주 여행\"}}"
```

## 2. 실제 데이터 연결하기 (선택, 무료)

먼저 `.env.example` 을 복사해 `.env` 로 이름을 바꿉니다. 아래에서 받은 키를 그 파일에 붙여 넣고 서버를 다시 켜면 됩니다.
미리보기 오른쪽 위에 "기차: 실제 · 장소검색: 연결"이라고 나오면 성공입니다.

**① 기차 시간표·관광공사 정보: `DATA_GO_KR_KEY`**
1. [공공데이터포털](https://www.data.go.kr)에 회원가입하고, 아래 두 API를 검색해 **활용신청**합니다. 개발계정은 보통 바로 승인됩니다.
   - `한국관광공사_국문 관광정보 서비스_GW` (TourAPI 4.0)
   - `국토교통부_(TAGO)_열차정보`
2. 마이페이지에서 **일반 인증키(Decoding)** 를 복사해 넣습니다.

**② 실제 가게·숙소 검색: `KAKAO_REST_API_KEY`**
1. [카카오 디벨로퍼스](https://developers.kakao.com)에 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**를 누릅니다.
2. **앱 키**에서 **REST API 키**를 복사해 넣습니다.
3. 앱 설정에서 **카카오맵(로컬) API 사용**을 켜야 하는 경우가 있습니다. 검색 결과가 안 나오면 이 설정을 확인하세요.

이 키를 넣으면 이렇게 달라집니다.
- 인기 여행지의 먹거리 카드에 **"추천 가게: OO식당"** 과 **[사진·후기 보기]** 버튼이 붙습니다.
- 그 밖의 지역은 실제 숙소·명소·식당이 나옵니다. 모텔과 패스트푸드는 뺍니다.

> 첫 실행 때 열차 API에서 전국 역 목록을 불러옵니다(수 초). 그 사이 들어온 요청은 예시 시간표로 답합니다.
> API가 느리거나 실패해도 예시 데이터로 대신 답하므로 챗봇이 멈추지 않습니다.

숙소 제휴 수익을 원하면 [아고다 파트너](https://partners.agoda.com)에 가입해 받은 ID를 `AGODA_CID` 에 넣으세요.
그러면 "가격·예약 보기" 버튼이 아고다 검색 결과로 연결됩니다. 비워 두면 네이버 검색으로 연결되는데, 네이버 검색에서는 여러 예약 사이트의 가격을 한 번에 볼 수 있습니다.

## 3. 카카오톡과 연결하기

카카오는 **인터넷에서 접속할 수 있는 https 주소**만 부를 수 있습니다.

### 3-1. 테스트용: 내 컴퓨터를 잠시 인터넷에 열기

[cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)를 설치한 뒤 서버를 켠 상태에서 실행합니다(가입 불필요).

```bash
cloudflared tunnel --url http://localhost:3000
```

화면에 나온 `https://xxxx.trycloudflare.com` 주소를 아래 스킬 URL에 씁니다. (ngrok도 됩니다.)

### 3-2. 오픈빌더 설정

1. [카카오톡 채널 관리자센터](https://business.kakao.com)에서 채널을 만듭니다.
2. [카카오 i 오픈빌더](https://chatbot.kakao.com)에서 **봇 만들기 → 카카오톡 챗봇**, 설정에서 위 채널을 연결합니다.
3. **스킬 → 생성**에서 URL에 `https://(내 주소)/skill` 을 넣고 저장합니다. "스킬서버로 전송"을 눌러 응답이 오는지 확인하세요.
4. **시나리오 → 폴백 블록**에서 봇 응답을 **스킬데이터 사용**으로 바꾸고, 위 스킬을 선택합니다.
   - 폴백 블록은 다른 블록에 걸리지 않는 모든 말을 받습니다. 그래서 "경주 여행", "부산에서 둘이 강릉"처럼 무엇을 보내든 이 서버가 답합니다.
5. **웰컴 블록**에도 같은 스킬을 연결합니다. 처음 들어온 분께 사용법이 나갑니다.
6. 오른쪽 위 **배포**를 누릅니다. 이후 카카오톡에서 채널을 찾아 대화해 보세요.

> 카카오는 스킬 서버의 답을 **5초까지만** 기다립니다. 이 서버는 외부 API마다 2초 제한을 두고, 4.5초가 지나면 "잠시 후 다시 보내 주세요"라고 답합니다.

## 4. 인터넷에 배포하기

Node.js를 실행할 수 있는 곳이면 어디든 됩니다. 실행 명령은 `npm start`, 포트는 `PORT` 환경변수를 따릅니다.

**Render (권장)**: 저장소에 [render.yaml](render.yaml)이 들어 있어서 **New → Blueprint** 로 고르면 아래 설정이 자동으로 채워집니다.
- 싱가포르 지역, 잠들지 않는 Starter 요금제, 지워지지 않는 디스크 1GB(`/var/data`)
- `DATA_DIR=/var/data`: 출발지 기억과 대화 기록이 재배포해도 남습니다.
- `ADMIN_TOKEN`: 결과 보고서 열쇠를 자동으로 만듭니다. 보고서 주소는 `https://(주소)/admin/report?key=(값)` 입니다.
- 키(`KAKAO_REST_API_KEY`, `DATA_GO_KR_KEY`)는 배포할 때 Render 화면에 직접 입력합니다.

git이 없어도 됩니다. **`업로드준비.bat`** 이 비밀 키를 뺀 업로드용 폴더를 만들어 주니, GitHub 웹 화면에 끌어다 놓으면 됩니다.
자세한 순서는 [docs/1단계-출시-가이드.md](docs/1단계-출시-가이드.md)에 있습니다.

**대화 기록**: 보낸 말, 챗봇이 알아들었는지, 버튼으로 보냈는지를 `DATA_DIR/logs/날짜.jsonl` 에 남깁니다.
카카오 사용자 키는 알아볼 수 없는 10자리 코드로 바꿔서 저장합니다. 끄려면 `LOG_CONVERSATIONS=off` 로 설정합니다.

> ⚠️ **무료 요금제는 쓰지 마세요.** Render 같은 서비스의 무료 서버는 한동안 요청이 없으면 잠들고, 깨어나는 데 수십 초가 걸립니다.
> 그러면 카카오의 5초 제한을 넘겨 첫 손님이 답을 받지 못합니다. **잠들지 않는 유료 최소 요금제**를 쓰세요.
> Railway, Fly.io, Google Cloud Run(최소 인스턴스 1), 네이버·카카오 클라우드도 같은 방법으로 배포할 수 있습니다.

```
│  ├─ parser.js          문장에서 여행지·출발지·날짜·인원 뽑기
│  ├─ kakao.js           카카오 응답 JSON 만들기 (글자 수 제한 처리)
│  ├─ links.js           예약·지도 링크
│  ├─ png.js             사진 없는 카드용 기본 그림
│  ├─ config.js          설정 (.env)
│  ├─ store.js           사용자별 지난번 출발지 기억 (DATA_DIR/users.json)
│  ├─ logger.js          대화 기록 (이름 없이, DATA_DIR/logs/)
│  ├─ report.js          테스트 결과 보고서 (/admin/report)

│  │  ├─ kakaoLocal.js   카카오 장소 검색
│  │  ├─ tour.js         관광공사 TourAPI (여행지 위치·주변 정보)

│  │  └─ http.js         공공데이터 API 호출
│  └─ data/
│     ├─ curated.js      ★ 인기 여행지 18곳 직접 고른 추천 (이유·가격대·걷기 난이도)
│     ├─ cities.js       전국 시·군 150곳 좌표 + 출발지 고르기 버튼 구성(지역별 목록)
│     ├─ stations.js     전국 주요 역 74곳 + 출발지 별칭

├─ public/preview.html   카톡 흉내 미리보기 화면
├─ test/                 자동 테스트 41개 (문장 해석 · 추천 데이터 · 카카오 형식 · 출발지 고르기 · 실제 API 응답 처리 · 기록·보고서)
├─ docs/                 기획·조사, 1단계 출시 가이드, 테스터 안내문
├─ render.yaml           Render 배포 설정
├─ 실행.bat / 테스트.bat / 업로드준비.bat   더블클릭 실행
└─ scripts/              try.js(한 문장 시험) · report.js(기록 요약) · pack.js(업로드 폴더 만들기)
```

### 추천 데이터 고치는 법

[src/data/curated.js](src/data/curated.js)를 메모장으로 열어 고치면 됩니다. 한 줄이 숙소, 가볼 곳, 먹거리 하나입니다.

```js
{ name: '힐튼 경주', price: '1박 15~25만원대', why: '보문호수 산책로 바로 앞', tip: '평지·엘리베이터' },
```

- 카카오톡 카드는 설명이 **2줄까지만** 보이니 `why` 와 `tip` 은 짧게(22자 이내) 쓰세요. `테스트.bat` 을 실행하면 길이를 확인해 줍니다.
- 새 지역을 추가할 때는 [src/data/destinations.js](src/data/destinations.js)에도 그 지역의 좌표를 넣으세요.
- 가격대와 운영 정보는 바뀝니다. 계절마다 한 번씩 점검하세요.

## 6. 알려진 한계 (다음 단계 후보)

- **SRT 시간표 없음**: SRT는 공개 API가 없어 "SRT도 있어요" 안내와 예매 링크만 줍니다.
- **갈아타는 기차 없음**: 직통 열차만 찾습니다. 직통이 없으면 코레일 사이트로 안내합니다.
- **예약 화면 자동 입력 안 됨**: 코레일·SRT는 출발역과 날짜를 미리 채운 링크를 공식으로 제공하지 않아 첫 화면으로 연결합니다.
- **숙소 실시간 가격 없음**: 직접 고른 추천에는 대략적인 가격대만 적었습니다. 그날그날 가격을 보여 주려면 아고다·부킹닷컴 제휴 API 승인이 필요합니다.
- **추천 데이터는 사람이 관리**: 18곳의 숙소·가게 이름과 가격대는 조사 시점 기준입니다. 문을 닫거나 가격이 바뀔 수 있으니 출시 전에 한 번 확인하세요.
- **문장 해석은 규칙 기반**: "다음주 토요일", "둘이", "1박2일" 같은 흔한 표현은 알아듣지만, 아주 자유로운 문장은 놓칠 수 있습니다. 필요하면 AI 모델(Claude 등)로 해석하는 단계를 추가할 수 있습니다. 이때도 5초 제한을 지켜야 합니다.
- **예시 데이터의 기차 시간·요금은 거리로 계산한 값**이라 실제와 다릅니다. 화면에 "예시예요"라고 표시합니다.
