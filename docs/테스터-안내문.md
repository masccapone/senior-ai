# 테스터 안내문

## 1. 카톡으로 보낼 초대 문구 (복사해서 쓰세요)

> 안녕하세요 😊 부탁 하나 드려도 될까요?
>
> 카카오톡에서 여행 계획을 도와주는 **'여행 도우미'** 를 만들고 있어요.
> 가고 싶은 곳을 말하면 **기차 시간, 숙소, 가볼 곳, 맛집**을 골라 줍니다.
>
> 👉 아래 링크를 누르고 **[채널 추가]** 를 눌러 주세요.
> (채널 링크)
>
> 그다음 채팅창에 이렇게 보내 보시면 돼요.
> · **경주 여행**
> · **부산에서 둘이 강릉 다음주 토요일**
>
> 일주일 정도 편하게 써 보시고, 나중에 5분만 소감을 들려주세요.
> 예약이나 결제는 하지 않으셔도 되고, 돈이 드는 일은 없어요.
> 보내신 말은 서비스를 고치는 데만 쓰고, 이름 없이 기록돼요. 🙏

## 2. 해 보시면 좋은 것 (미션)

초대 문구 다음에 따로 보내도 좋습니다. 하나씩 천천히 해 보시면 됩니다.

1. 채널을 추가하고 아무 말이나 보내 보기
2. **가고 싶은 곳** 한 곳을 물어보기 (예: "여수 여행")
3. 답 아래 **[출발지 바꾸기]** 를 눌러 **사는 곳**으로 바꾸기
4. 숙소 카드의 **[가격·예약 보기]** 를 눌러 보기
5. 사진처럼 옆으로 넘기는 카드를 끝까지 넘겨 보기
6. **내 말투 그대로** 물어보기 (예: "엄마 모시고 바다 보러 가고 싶어")
7. 며칠 뒤, 생각날 때 한 번 더 써 보기

## 3. 끝나고 물어볼 질문 (전화나 만나서 5분)

답을 받아 적을 때는 **본인이 쓴 표현 그대로** 적어 주세요.

1. 처음 채널에 들어갔을 때 **무엇을 해야 할지** 바로 알겠던가요?
2. 쓰다가 **막히거나 당황한 순간**이 있었나요? 어디서요?
3. 버튼을 누르는 게 편했나요, 글자로 쓰는 게 편했나요?
4. 추천해 준 숙소·가볼 곳·맛집이 **믿음이 갔나요?** 아니라면 왜 그랬나요?
5. 글자 크기와 글의 양은 어땠나요? (너무 많다 / 적당하다 / 부족하다)
6. 실제로 여행 갈 때 **또 쓸 것 같나요?** (1점 전혀 아니다 ~ 5점 꼭 쓰겠다)
7. 여행 말고 **카톡으로 이런 걸 물어볼 수 있으면 좋겠다** 싶은 게 있나요? (쇼핑, 병원, 날씨 등)
8. 주변 분께 **소개하고 싶은가요?** 왜요?

## 4. 지켜보실 때 메모할 것 (운영자용)

- 처음 메시지를 보내기까지 걸린 시간
- 멈칫하거나 화면을 위아래로 헤맨 곳
- 누르려다 못 누른 버튼, 잘못 누른 버튼
- 혼잣말 ("이게 뭐지?", "어디 눌러?")
- 도움을 요청한 순간과 무엇을 물었는지

> 도와주고 싶어도 꾹 참는 것이 가장 중요합니다. 막히는 그 순간이 고칠 곳입니다.
