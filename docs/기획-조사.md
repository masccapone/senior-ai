# 기획 · API 조사 · 화면 설계

조사일: 2026-10-26

## 1. 합의된 MVP 범위

| 항목 | 결정 |
|---|---|
| 예약 | **추천 + 예약 링크만**. 결제와 예약은 코레일·SRT·숙소 사이트에서 직접 |
| 입력 방식 | **문장 한 번에**. 예) "부산에서 둘이 경주 다음주 토요일". 빠진 날짜·인원은 기본값(다가오는 토요일 · 1박 · 2명)으로 채우고 화면에 알려 줌 |
| 출발지 (2·3차 수정) | 문장에 쓴 출발지 → 그 사용자의 **지난번 출발지** → 서울 순서로 정함. **전국 150개 시·군** 지원. [출발지 바꾸기]는 2단계: 1단계 [서울][부산][대구][대전][광주][경기·인천][강원][충청][전라][경상] → 2단계 시·군 8곳씩 + [다음 ▶]. 고른 곳은 기억함. 역이 없는 곳은 가까운 역(가능하면 KTX역)을 "기차는 ○○역에서 타요"로 안내. "해남에서", "김천 출발", "부산발", "철원 → 강릉", "홍천 담양"도 알아들음. 일상 단어와 겹치는 지명(예산·장수 등)은 "에서·출발"이 붙을 때만 지명으로 봄 |
| 지역 | **전국**. 역 74곳과 여행지 62곳을 내장했고, 키를 넣으면 관광공사 검색으로 그 밖의 지명도 찾음 |
| 추천 항목 | 기차, 숙소, 가볼 곳, 먹거리 |
| 추천 방식 (2차 수정) | 인기 여행지 18곳은 **직접 고른 추천**을 보여 줌. 숙소는 가격대·걷기 편의, 가볼 곳은 머무는 시간·걷기 난이도, 먹거리는 가격대를 함께 적음. 카카오 키가 있으면 먹거리에 실제 가게를 붙임. 그 밖의 지역은 카카오 장소 검색 → 관광공사 → 카카오맵 링크 순서로 대체 |
| 전화 상담 | 넣지 않음 |

## 2. 구현 방식 조사 결과

| 구분 | 후보 | 쓸 수 있나 | 승인·조건 | 비용 | 이번 MVP |
|---|---|---|---|---|---|
| 카카오톡 연동 | 카카오 i 오픈빌더 + 스킬 서버 | ✅ | 카카오톡 채널과 오픈빌더 봇 생성. 스킬은 **5초 안에 응답**해야 함. AI 챗봇 콜백을 신청하면 최대 1분까지 늘릴 수 있음 | 무료 | 사용 |
| 기차 (코레일) | 국토교통부 (TAGO) 열차정보 API | ✅ | 공공데이터포털 활용신청. 출발·도착역과 날짜로 KTX를 포함한 코레일 열차 시간표 조회 | 무료. 개발계정 1일 10,000건, 활용사례를 등록하면 늘릴 수 있음 | 사용 |
| 기차 (SRT) | SR 공식 API | ❌ 공개 API 없음 | — | — | 예매 링크만 |
| 기차 (예매) | 코레일·SRT 예매 API | ❌ 일반에 공개하지 않음 | 제휴 계약 필요 | — | 링크로 대체 |
| 관광·숙소·맛집 | 한국관광공사 TourAPI 4.0 (KorService2) | ✅ | 공공데이터포털 활용신청. 키워드 검색, 위치 기반 검색, 숙박·음식점 분류 제공. 가격 정보는 없음 | 무료. 개발계정 일일 한도가 있고 운영계정으로 늘릴 수 있음 | 사용 |
| 실제 가게·숙소 검색 | 카카오 로컬 API (키워드·카테고리 장소 검색) | ✅ | 카카오 디벨로퍼스 앱의 REST API 키. 숙박 AD5 · 음식점 FD6 · 관광명소 AT4. 반경 최대 20km, 1회 최대 15곳. 결과마다 카카오맵 상세페이지(사진·후기) 링크 | 무료(일일 한도 있음) | 사용 (2차 수정) |
| 숙소 예약 | 아고다 파트너 | ✅ 링크 제휴는 가입 즉시 가능. API는 별도 승인 | partners.agoda.com 가입 | 무료. 예약이 생기면 수수료 수입 | 제휴 ID가 있으면 링크에 넣음 |
| 숙소 예약 | 부킹닷컴 Affiliate / Demand API | △ API는 Managed Affiliate 승인과 계약이 필요하고, 약관상 AI 활용에 별도 서면 승인이 필요하다는 2차 자료가 있음 | 파트너십팀 협의 | 무료. 수수료 수입 | 다음 단계 |
| 숙소 예약 | 야놀자 · 여기어때 | ❌ 공개 제휴 API 없음 | 사업 제휴 협의 | — | 제외 |

**결론**
- MVP는 **공공 API 두 개와 카카오 장소 검색(모두 무료), 직접 고른 추천 데이터, 예약 링크**로 충분합니다.
- 수익화가 필요해지면 아고다 제휴 ID부터 넣고, 이후 부킹닷컴이나 아고다 API 승인을 추진합니다.
- 기차 예매 연동은 코레일·SR과 사업 제휴를 맺어야 해서 MVP 범위 밖입니다.

## 3. 50대 이상을 위한 화면 설계

카카오톡 글자 크기는 각 사용자의 휴대폰 설정을 따르므로 챗봇이 바꿀 수 없습니다.
대신 **읽을 양을 줄이고, 누를 곳을 크고 분명하게** 만들었습니다.

### 원칙
1. **한 번에 끝내기**: 문장 하나로 기차, 숙소, 가볼 곳을 모두 보여 줍니다. "출발지는요? 날짜는요?"처럼 되묻지 않고, 기본값을 쓴 뒤 무엇을 가정했는지 알려 줍니다.
2. **말풍선 3개, 늘 같은 순서**: ① 요약 → ② 기차 목록 → ③ 숙소·관광 카드. 매번 같은 자리에 같은 정보가 나옵니다.
3. **기차는 옆으로 넘기지 않는 목록 한 장**: 출발·도착 시간과 일행 전체 요금을 위아래로 바로 비교합니다. 옆으로 넘기는 카드는 처음 쓰는 분이 놓치기 쉽습니다.
4. **요금은 일행 합계로**: "2명 98,600원"처럼 실제로 낼 금액을 보여 줍니다.
5. **그림 기호로 구분**: 🚆 기차, 🏨 숙소, 📍 가볼 곳, 🍚 먹거리.
6. **버튼은 세로로, 짧은 동사로**: "코레일에서 예매", "가격·예약 보기", "지도에서 보기". 가로 버튼은 작아서 쓰지 않습니다.
7. **바로가기 버튼으로 다음 행동 안내**: 가볼 곳 더보기 · 먹거리 더보기 · 숙소 더보기 · 일주일 뒤로 · 처음으로. 버튼은 완전한 문장을 보내므로 서버가 대화를 기억하지 않아도 조건이 유지됩니다.
8. **모르면 예시로 다시 묻기**: 여행지를 못 알아들으면 "예) 경주 여행"과 인기 여행지 버튼을 보여 줍니다.
9. **예시 데이터는 예시라고 밝히기**: 키 없이 계산한 기차 시간·요금에는 "예시예요. 예매 화면에서 꼭 확인해 주세요"를 붙입니다.
10. **기차로 못 가는 곳은 바로 알려 주기**: 제주·울릉도는 "비행기로 가요"와 항공권 검색 버튼을 보여 줍니다. 역에서 15km 넘게 떨어진 곳은 "역에서 버스·택시로 약 ○○km"를 함께 알려 줍니다.

### 대화 흐름

```
[처음 들어옴] ─▶ 사용법 + [경주 여행][부산 여행][강릉 여행][전주 여행][여수 여행]
      │
      ▼  "부산에서 둘이 경주 다음주 토요일"
┌─ ① 요약 ────────────────┐
│ 🧳 경주 여행 추천이에요     │
│ 📍 출발  부산               │
│ 📅 날짜  11월 7일(토) · 1박 │
│ 👥 인원  2명                │
└────────────────────────┘
┌─ ② 🚆 부산역 → 신경주역 ──┐
│ KTX 07:30 출발 → 08:10 도착 │
│ 40분 · 2명 27,800원          │
│ … (최대 3편 + SRT 안내)       │
│ [ 코레일에서 예매 ]           │
└────────────────────────┘
┌─ ③ 옆으로 넘기는 카드 ─────┐
│ 🏨 숙소 2 · 📍 가볼 곳 2 · 🍚 먹거리 1 │
│ [가격·예약 보기] [지도에서 보기] │
└────────────────────────┘
[가볼 곳 더보기][먹거리 더보기][숙소 더보기][일주일 뒤로][처음으로]
```

## 4. 다음 단계 제안
1. 키를 넣고 실제 데이터로 미리보기를 확인합니다. 지역마다 추천 품질도 살펴봅니다.
2. 부모님 세대 5~10명에게 써 보게 하고, 막히는 지점을 기록합니다.
3. 아고다 제휴 ID를 넣어 예약 수수료 수익을 확인합니다.
4. 자유로운 문장을 더 잘 알아듣도록 AI 해석 단계를 넣을지 검토합니다. 5초 제한을 지켜야 하고, 길어지면 콜백 방식을 씁니다.
5. 사용 기록을 저장해 인기 여행지와 재방문을 확인합니다. 지금은 아무것도 저장하지 않습니다.
