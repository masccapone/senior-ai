# 1단계: 실제 카카오톡으로 테스트하기

목표: 어르신 5~10명이 **실제 카카오톡**에서 1~2주 써 보고, 어디서 막히는지 기록으로 확인하기.

전체 흐름은 아래와 같습니다. 한 번에 끝내지 않아도 되고, 위에서부터 차례로 하시면 됩니다.

```
① 카카오톡 채널 만들기  →  ② 코드를 GitHub에 올리기  →  ③ Render에 배포(인터넷 주소 생김)
  →  ④ 오픈빌더 챗봇에 주소 연결  →  ⑤ 테스터 초대  →  ⑥ 보고서 보기
```

### 준비물
| 무엇 | 어디서 | 비용 |
|---|---|---|
| 카카오 계정 | 지금 쓰시는 계정 | 무료 |
| GitHub 계정 | [github.com](https://github.com) 가입 | 무료 |
| Render 계정 + 결제 카드 | [render.com](https://render.com) (GitHub로 로그인) | 서버 월 7달러 + 저장 디스크 1GB 월 0.25달러, **합쳐서 월 1만 원 남짓** |
| 카카오 REST API 키 | 이미 `.env` 에 넣어 둠 | 무료 |
| 공공데이터포털 키 (선택) | 없으면 기차 시간표가 예시로 나옴 | 무료 |

---

## ① 카카오톡 채널 만들기 (10분)

1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com) → **새 채널 만들기**
2. 채널 이름(예: `여행 도우미`), 검색용 아이디, 프로필 사진, 소개 문구를 입력합니다.
   - 소개 문구 예: "가고 싶은 곳을 말하면 기차·숙소·가볼 곳을 골라 드려요"
3. 채널 설정에서 **채널 공개**와 **검색 허용**을 켭니다.
4. 채널 주소(예: `pf.kakao.com/_xxxxx`)를 메모해 둡니다. 테스터에게 보낼 링크입니다.

> ⚠️ **먼저 확인할 점**: 사업자등록이 없는 개인 채널도 챗봇을 연결할 수 있는지, 카카오 공식 안내로 확인하지 못했습니다.
> ④단계에서 오픈빌더가 채널 목록에 이 채널을 보여 주지 않으면 "비즈니스 채널"로 바꿔야 하는 것일 수 있습니다.
> 그때는 [카카오비즈니스 고객센터](https://cs.kakao.com)에 "개인 채널에 오픈빌더 챗봇 연결이 가능한지" 물어보세요.
> 그래서 ④단계의 연결 시도를 **가장 먼저** 해 보시는 것도 방법입니다.

---

## ② 코드를 GitHub에 올리기 (10분)

1. 내 PC의 프로젝트 폴더(바탕화면 `claud\travel-bot`)에서 **`업로드준비.bat`** 을 더블클릭합니다.
   → 바탕화면 `claud` 안에 **`senior-ai-업로드용`** 폴더가 생기고 자동으로 열립니다.
   (비밀 키가 든 `.env` 와 Node 실행 파일은 자동으로 빠지고, 키가 섞이지 않았는지도 검사합니다.)
2. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
   - 이름: `senior-ai`
   - **Private**(비공개)를 선택합니다.
   - **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. `senior-ai-업로드용` 폴더 **안의 것 전부**(src, docs 등 폴더 포함)를 선택해서 브라우저 화면에 끌어다 놓습니다.
5. 아래 **Commit changes**를 누릅니다.

> 코드를 고친 뒤 다시 올릴 때도 1·3~5번을 반복하면 됩니다. 같은 이름의 파일은 덮어씁니다.

---

## ③ Render에 배포하기 (15분)

1. [render.com](https://render.com) → **Get Started** → **GitHub로 로그인**합니다. GitHub 저장소 접근 권한을 물으면 `senior-ai` 저장소를 허용합니다.
2. 대시보드에서 **New +** → **Blueprint** → `senior-ai` 저장소를 고릅니다.
   - 저장소의 `render.yaml` 을 읽어서 설정이 자동으로 채워집니다. 서버는 싱가포르(한국과 가까움), 잠들지 않는 Starter 요금제, 기록 저장 디스크 1GB입니다.
3. 입력칸이 나오면 넣어 주세요.
   - `KAKAO_REST_API_KEY`: 내 PC의 `claud\travel-bot\.env` 파일을 메모장으로 열어 같은 이름 줄의 값을 복사합니다.
   - `DATA_GO_KR_KEY`: 받았으면 입력하고, 없으면 비워 둡니다.
   - `AGODA_CID`: 비워 둡니다.
4. **Apply**를 누르고, 결제 카드를 등록합니다.
5. 몇 분 뒤 화면 위쪽에 주소가 생깁니다(예: `https://senior-ai-abcd.onrender.com`).
   - 브라우저에서 `주소/health` 를 열어 `{"ok":true …}` 가 나오면 성공입니다.
   - 그냥 `주소` 를 열면 지금까지 보시던 카톡 흉내 미리보기가 나옵니다.

**결과 보고서 주소 만들기**
- Render → `senior-ai` 서비스 → **Environment** → `ADMIN_TOKEN` 값을 복사합니다(Render가 자동으로 만든 긴 문자열).
- 보고서 주소는 `https://(내 주소)/admin/report?key=(복사한 값)` 입니다. 즐겨찾기 해 두세요.
- 이 주소는 **비밀번호와 같습니다.** 다른 사람에게 보내지 마세요.

## ④ 오픈빌더에서 챗봇 연결하기 (20분)

1. [카카오 i 오픈빌더](https://chatbot.kakao.com) → **봇 만들기** → **카카오톡 챗봇**. 이름은 `여행 도우미`로 합니다.
2. 왼쪽 **설정** → **카카오톡 채널 연결** → ①에서 만든 채널을 선택합니다. 목록에 없으면 ①의 "먼저 확인할 점"을 보세요.
3. 왼쪽 **스킬** → **생성**
   - 스킬 이름: `여행추천`
   - URL: `https://(내 주소)/skill`
   - **기본 스킬로 설정**에 체크하고 **저장**합니다.
   - 오른쪽 **스킬서버로 전송**을 누르고, 아래에 `"version":"2.0"` 으로 시작하는 응답이 오면 연결된 것입니다.
4. 왼쪽 **시나리오** → **폴백 블록**
   - 아래 **봇 응답**에서 **스킬데이터 사용**을 고릅니다.
   - 위 **파라미터 설정**에서 스킬을 `여행추천`으로 고르고 **저장**합니다.
   - 폴백 블록은 "다른 블록에 걸리지 않는 모든 말"을 받습니다. 그래서 무엇을 보내든 우리 서버가 답합니다.
5. **웰컴 블록**도 같은 방법으로 `여행추천` 스킬에 연결합니다. 채널에 처음 들어온 분께 사용법이 나갑니다.
6. 오른쪽 위 **봇 테스트**에서 "경주 여행"을 보내 카드가 나오는지 확인합니다.
7. 왼쪽 **배포** → **배포**를 누릅니다.
8. 내 카카오톡에서 채널을 친구 추가하고 직접 대화해 봅니다. 이것이 진짜 첫 테스트입니다.

> 다른 블록(기본으로 들어 있는 예시 블록 등)이 있으면 "경주"같은 말을 가로챌 수 있습니다. 폴백·웰컴 외의 블록은 지우거나 비워 두세요.

## ⑤ 테스터 초대 (1~2주)

- [테스터 안내문](테스터-안내문.md)의 초대 문구를 카톡으로 보냅니다. 채널 링크를 함께 보내 주세요.
- 5~10명이면 충분합니다. **스마트폰에 익숙하지 않은 분을 꼭 1~2명 넣으세요.** 그분들이 막히는 곳이 가장 값진 정보입니다.
- 가능하면 한두 분은 **옆에서 쓰는 모습을 지켜보세요.** 도와주지 말고, 멈칫하는 순간을 메모합니다.

## ⑥ 보고서 보기

보고서 주소를 열면 이런 내용이 나옵니다.
- **써 본 사람 수**, 이틀 이상 다시 온 사람 수
- **알아들은 비율**과 **못 알아들은 말 목록**. 가장 중요한 부분입니다. 어르신들이 실제로 어떻게 말하는지 그대로 보입니다.
- 직접 쓴 말과 버튼 비율, 출발지를 바꾸지 않고 서울 기본값으로 본 비율
- 인기 여행지와 출발지, 날짜별 사용량, 사용자별 사용량(이름 없이 코드로)

테스트가 끝나면 보고서 화면의 **logs.jsonl**(원본 기록)을 내려받아 주세요. 그 파일과 인터뷰 메모를 주시면 개선 목록을 함께 만들겠습니다.

## 문제가 생기면

| 증상 | 확인할 곳 |
|---|---|
| 카톡에서 답이 없음 / "스킬 서버 응답 오류" | 브라우저로 `주소/health` 열기 → 안 열리면 Render 화면의 **Logs** 확인 |
| 오픈빌더 "스킬서버로 전송"이 실패 | 스킬 URL 끝이 `/skill` 인지, `https://` 로 시작하는지 |
| 카톡에서 엉뚱한 블록이 답함 | 시나리오에 폴백·웰컴 외 블록이 남아 있는지 |
| 장소 검색 결과가 안 나옴 | Render **Environment**에 `KAKAO_REST_API_KEY` 가 있는지, 카카오 디벨로퍼스에서 카카오맵이 켜져 있는지 |
| 보고서가 "Not found" | 주소의 `key=` 값이 `ADMIN_TOKEN` 과 똑같은지 |

## 개인정보 메모
- 이름, 전화번호, 카카오 아이디는 받지도 저장하지도 않습니다. 사용자는 알아볼 수 없는 10자리 코드로만 구분합니다.
- 보낸 말은 그대로 남습니다. 처음 인사에서 "보내신 말을 이름 없이 기록해요"라고 알립니다. 테스터에게도 미리 말해 주세요.
- 테스트가 끝나 정식 서비스로 넘어갈 때는 개인정보처리방침과 기록 보관 기간을 정해야 합니다.
